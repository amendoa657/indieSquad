# De onde veio esta pasta

A `mosaic-ui` é a biblioteca de interface da **Mosaic Store**
(https://github.com/amendoa657/mosaicStore), feita pelo Thales e pelo Ítalo.
Ela foi copiada pra cá inteira, sem alteração: a identidade da IndieSquad é
aplicada por fora, em `static/style/tema-indiesquad.css`, que só redefine os
tokens `--mo-*`.

Manter esta pasta intocada é de propósito. Quando a biblioteca mudar lá, dá
pra trazer a versão nova por cima sem perder nada daqui.

A Mosaic Store é distribuída sob **GPL-3.0**. Como os dois autores da
biblioteca são integrantes deste trabalho, o uso aqui está acertado entre
eles; se este repositório for publicado, vale incluir o aviso de licença
correspondente.

As fontes (Space Grotesk e JetBrains Mono) são SIL OFL 1.1, com as licenças
em `fontes/LICENSE-*.txt`.
